# Whisper Voice Input

Локальный голосовой ввод: зажмите клавишу, скажите фразу — текст появится в активном окне. Whisper работает на вашем GPU, ничего не уходит в облако.

```
[Windows]  VoiceInput.exe ──── F8 (удерживать) ──── говорите ──── отпустите
                │                                          │
                ▼                                          ▼
        sounddevice (микрофон)                    текст → Ctrl+V в активное окно
                │                                          ▲
                ▼                                          │
[WSL/Linux]  faster-whisper (large-v3-turbo, int8, CUDA) ──┘
             http://localhost:8000 — OpenAI-совместимый API
```

## Возможности

- **Режим рации (push-to-talk)** — зажали клавишу → говорите → отпустили → текст вставлен
- **Локально и приватно** — распознавание на вашем GPU, аудио не покидает машину
- **Быстро** — large-v3-turbo int8: ~1–2 сек на фразу (GTX 1070)
- **Живой индикатор у курсора** — точка: белая (ожидание) / зелёная с пульсом от голоса (запись) / оранжевая с радаром (расшифровка)
- **Трей + настройки** — выбор микрофона, язык, хоткеи, чувствительность
- **OpenAI-совместимый API** — `/v1/audio/transcriptions`, работает с любыми клиентами OpenAI

## Состав

| Путь | Что это |
|---|---|
| `voice_input.py` | GUI-клиент для Windows (PySide6, трей, индикатор) |
| `build.sh` | Сборка клиента в один `VoiceInput.exe` (запускать из WSL/Git Bash) |
| `run.sh` | Запуск клиента (exe или из исходника) |
| `server/` | Whisper-сервер (FastAPI + faster-whisper, CUDA) |

## Установка

### Сервер (WSL/Linux)

Требуется NVIDIA GPU + драйвер (`nvidia-smi` должен работать в WSL).

```bash
cd server
./run.sh        # при первом запуске сам создаст venv и поставит зависимости
```

Модель `deepdml/faster-whisper-large-v3-turbo-ct2` (~1.6 GB) скачается автоматически при первом старте. Если сеть медленная — можно положить модель в `~/.cache/huggingface/hub/` вручную.

Проверка:

```bash
curl http://localhost:8000/health
# {"status":"ok","model":"...","device":"cuda","compute":"int8"}
```

### Клиент (Windows)

Python 3.10+ и один из вариантов:

**Готовый exe** — собрать один раз:
```bash
./build.sh        # из WSL → dist/VoiceInput.exe
```

**Из исходника:**
```cmd
pip install numpy sounddevice requests PySide6 keyboard
python voice_input.py
```

## Использование

| Действие | Эффект |
|---|---|
| Зажать `F8` | Запись (индикатор зелёный, пульсирует от голоса) |
| Отпустить `F8` | Отправка на сервер (оранжевый радар) → текст вставляется в активное окно |
| `Ctrl+Alt+Esc` | Отменить запись без отправки |
| Двойной клик по иконке в трее | Настройки |

В настройках: микрофон (список + проверка), URL сервера, язык (ru/en/auto), хоткеи, режим (рация/переключатель), автостоп по тишине.

Запись не прерывается по тишине в режиме рации — пишется, пока держите клавишу (максимум настраивается, по умолчанию 5 минут).

## Параметры сервера

| Переменная | По умолчанию | Описание |
|---|---|---|
| `WHISPER_MODEL` | `deepdml/faster-whisper-large-v3-turbo-ct2` | Модель (HF hub или путь) |
| `WHISPER_COMPUTE` | `int8` | `int8` / `float16` / `float32` |
| `WHISPER_DEVICE` | `cuda` | `cuda` / `cpu` |
| `WHISPER_PORT` | `8000` | Порт |

## Решение проблем

- **Сервер недоступен** — проверьте `curl localhost:8000/health`; в WSL2 порт доступен из Windows автоматически
- **«Слишком тихо»** — выберите правильный микрофон в настройках, уменьшите порог тишины
- **Текст не вставляется** — некоторые приложения (RDP, игры) блокируют синтетический ввод; текст остаётся в буфере обмена
- **CUDA не находится** — убедитесь, что `nvidia-cublas-cu12` установлен в venv сервера (run.sh делает это сам)

## Требования

- Windows 10/11 + WSL2 (или любой Linux) с NVIDIA GPU (≥4 GB VRAM)
- Python 3.10+ (Windows и WSL)
